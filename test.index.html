Core BCA Subjects

1. Programming Fundamentals (C/C++)

Focuses on basic programming concepts, data types, control structures, functions, arrays, and Object-Oriented Programming (OOP) principles.

Key Topics: Loops, Pointers, Structures, Classes, Inheritance, Polymorphism.

Resource Link: Download C++ Quick Guide (Mock PDF)

2. Database Management System (DBMS)

Covers database architecture, data models (ER Model, Relational Model), Relational Algebra, and Structured Query Language (SQL).

Key Topics: Normalization (1NF, 2NF, 3NF, BCNF), Transactions, Concurrency Control, Indexing.

Resource Link: SQL Essential Commands Cheat Sheet

3. Web Technology

An introduction to client-side and server-side web development technologies including HTML5, CSS3, and JavaScript basics.

Key Topics: DOM Manipulation, Responsive Design, CSS Flexbox/Grid, Client-Server Architecture.

Resource Link: HTML/CSS/JS Project Ideas
